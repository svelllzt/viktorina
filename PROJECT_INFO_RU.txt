QuizLab — техническая сводка проекта
====================================

1) Назначение
-------------
QuizLab — веб-приложение для создания, публикации и проведения викторин.
Поддерживает:
- обычное прохождение по ссылке;
- live-проведение с ведущим (синхронное переключение вопросов).


2) Стек технологий
------------------
Backend:
- Python 3.11+
- FastAPI
- SQLAlchemy async
- SQLite (aiosqlite)
- Jinja2 templates

Frontend:
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js (через CDN)
- Font Awesome 6 Free
- Google Fonts

Realtime и интеграции:
- fastapi.WebSocket
- qrcode[pil] (генерация QR)
- smtplib + asyncio.to_thread (почта)

Безопасность/авторизация:
- JWT (python-jose)
- Пароли через passlib[bcrypt]
- itsdangerous (подписанные cookie play/live-сессий)


3) Архитектура
--------------
- Монолитный backend в main.py.
- Шаблоны в templates/.
- Статика в static/.
- БД: локальный файл quiz.db.
- Конфиг по SMTP/админу:
  - базовые значения в config.py;
  - runtime-изменения через runtime_config.json.


4) Основные сущности БД
-----------------------
- User
- Quiz
- Question
- AnswerOption
- Attempt
- AttemptQuestionDeadline
- UserAnswer

Ключевые флаги Quiz:
- status (draft/published/closed)
- access_type (public/password)
- is_live (включен ли live-режим)
- live_pin и поля текущего состояния live-сессии.


5) Как реализованы режимы
-------------------------
Обычный режим:
- Пользователь открывает /play/{code}
- Создается Attempt
- Вопросы выдаются по порядку
- Время контролируется на сервере
- После завершения — результат и таблица

Live-режим:
- Автор открывает live-сессию
- Генерируется PIN + QR
- Участники заходят по /join/{pin}
- Ведущий запускает и вручную переключает вопросы
- Статистика и состояние обновляются через WebSocket
- После завершения участники получают результаты


6) Realtime-модель
------------------
Используется LiveHub (in-memory менеджер соединений):
- отдельные каналы для ведущего и участников;
- группировка по live_pin;
- рассылка событий:
  - подключение участников;
  - старт/следующий вопрос/финиш;
  - обновление статистики ответов.


7) Почта и восстановление пароля
--------------------------------
- Эндпоинты:
  - /forgot-password
  - /reset-password
- Отправка SMTP вынесена в функцию и выполняется через asyncio.to_thread.
- SMTP редактируется в админке: /admin/settings.


8) Админ-функции
----------------
- /admin/featured — модерация витрины.
- /admin/settings — SMTP настройки и тест-письмо.


9) Витрина и каталог
--------------------
- Главная: топ-квизы по числу прохождений (из featured + published).
- /quizzes: каталог витринных квизов.


10) Тестовые данные
-------------------
Скрипт test.py:
- создает до 10 демо-квизов;
- минимум 5 от admin;
- заполняет вопросы и варианты;
- очищает устаревшие сидовые данные перед генерацией.

Запуск:
python test.py


11) UX/ошибки
-------------
- Добавлены HTML-страницы ошибок (404 и прочие HTTP ошибки).
- Для технических JSON/fetch-эндпоинтов ошибки остаются в JSON, чтобы не ломать JS.


12) Запуск проекта
------------------
1. Установить зависимости:
   pip install -r requirements.txt
2. Старт:
   uvicorn main:app --reload
3. Открыть:
   http://127.0.0.1:8000


13) Что важно учитывать
-----------------------
- Сейчас sqlite + in-memory live-hub: для single-instance деплоя подходит, для горизонтального масштабирования нужен внешний broker/store.
- main.py большой, при дальнейшем развитии лучше делить на модули (routers/services/models).
